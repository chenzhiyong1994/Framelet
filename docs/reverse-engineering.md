# FastStone Capture 10.3 结构与行为证据

本报告来自对 FastStone Capture 10.3 安装样本的只读结构分析。没有反编译或复制实现代码，没有把原版图标、位图、音效、语言包或注册数据加入 Framelet。仓库提供可复现实验脚本 `analysis/binary_probe.py`；安装样本、用户配置和生成的分析结果不随源码发布。配置值是被观察样本的状态，不代表厂商默认值；语言字符串能证明功能入口及提示存在，不能单独证明每条功能已运行成功。

## 技术证据

- 四个 EXE 均为 PE32/x86（Machine=0x14c）；节名包含 `CODE`、`DATA`、`BSS`、`.idata`、`.tls`、`.rdata`、`.reloc`、`.rsrc`。
- `fsc.db`、`fsrec.db`、`TBSettings.db` 以 `TPF0` 起始，是 Delphi 组件流，根类为 `TProgramSettings` 或 `TTextBoardSettings`。配合 VCL 类和资源名称，能够高置信判断这是原生 Delphi/VCL 产品；这些 `.db` 不是 SQLite。
- 主程序显式导入 `GetDC`、`GetWindowDC`、`BitBlt`、`StretchBlt`、`CreateDIBSection`、`GetCursorInfo`、`RegisterHotKey`、`SetWindowsHookEx` 等 Win32/GDI API，支持其屏幕采集、全局热键、光标合成与原生窗口工作方式。导入表只能证明 API 可用，无法证明全部截图路径都经由这些函数。
- `FSRecorder.exe` 独立于主程序，导入 `winmm.dll`、`avifil32.dll`、`MsVfW32.dll` 等多媒体组件。不能从静态导入表独断完整编码器实现。
- `.fslang` 文件头由魔数、版本、窗体数量构成；每个窗体记录类名、下一窗体绝对偏移，再按控件名、类型、原始窄字节字符串、UTF-16 译文记录内容。两份语言包均识别出 75 个窗体、2236 个首组控件条目。
- 当前 `StartToTray=true`、`AutoHide=true`。因此启动后没有可见窗口可能是预期状态。设置提示说明，工具条拖到屏幕顶部时可以自动隐藏。

## 捕捉交互契约

| 模式 | 语言资源直接提供的操作提示 |
| --- | --- |

## 快捷键与参数

配置保存 15 组捕捉热键，采用 Win32 虚拟键值和修饰键位掩码。当前前六组均使用 `VK_SNAPSHOT=44`，修饰位依次为 1、4、2、6、0、3，对应 Alt、Shift、Ctrl、Ctrl+Shift、无、Ctrl+Alt。它们与设置控件中前六种捕捉模式顺序吻合。第 10 组修饰位为 7，应以 UI 核对其究竟绑定固定区域还是其他动作；不能仅凭顺序把它当作“重复捕捉”。

图像编辑快捷键文字核实：Ctrl+O 打开，Ctrl+S 保存，Ctrl+Z/Y 撤销/重做，Ctrl+C/X/V 复制/剪切/粘贴，Ctrl+R 调整尺寸，Ctrl+Q 扩展画布，Ctrl+P 打印，Ctrl+G 图像转 PDF，Ctrl+H 合并图像，Ctrl+1–0 工作区。绘图文本 Enter 换行，Ctrl+Enter 结束编辑。

录屏当前帧率 15；可包含/高亮鼠标与点击，录制系统声音、麦克风或两者，鼠标点击声、摄像头、控制条和闪烁边框。配置中第一录屏热键为 F11，第二为 Ctrl+F11；具体动作需结合运行界面核对。当前 `DefaultSaveAsMP4=true`。

## 实现验证建议与证据边界

首先验证真实截图像素、坐标和输出，尤其是多显示器负坐标、DPI、选择时隐藏自身、取消后恢复工具条、捕捉鼠标、两角选择、固定尺寸和重复区域。滚动捕捉要用可预测内容验证拼接，避免把简单纵向拼接误报为完整滚动捕捉。

随后验证编辑操作和文件保存能否重新打开、撤销是否保存独立快照、输出路由是否真实完成、录屏文件是否可播放。UI 字符串和配置参数只能作为需求证据，不能充当功能验证结果。截图、动画、图标和原始资源尚未经过本报告分析；本报告不主张像素级界面一致，也不主张已证明所有原版行为。

探针复现方式（Python 标准库即可；需要自行提供安装目录）：

```powershell
python analysis/binary_probe.py '<installation-directory>' --output analysis/binary-evidence.json
```

探针默认丢弃注册/身份、最近文件、历史、文件夹、文件路径、缓存等字段；不导出 PE 资源内容。原版文件保持只读。输出仅供本地分析，`analysis/binary-evidence.json` 不纳入 Git；不同版本或配置的样本会产生不同结果。
