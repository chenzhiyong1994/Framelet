## 已修复并复查的问题

- 编辑器菜单使用不合法的裸 Escape 快捷键导致首次构造失败：改为键盘处理，加入窗口构造检查。
- 绘图底部按钮遮挡：调整为明确的布局容器，检查默认和最小尺寸，并实际绘图提交。
- PDF 导出误改源文件路径/保存检查点，以及边缘、标题、马赛克对透明度的影响：分别加入行为与像素检查。
- 快捷键设置变化后提示仍显示旧组合：工具栏与托盘按当前配置生成显示文本。
- 重复发布文档出现 docs/docs 嵌套：改为逐文件按相对路径覆盖，隔离目录连续两次发布逻辑校验通过。
