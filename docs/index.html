GOOD TO KNOW

开始前，
你可能想知道。

完整功能与边界 ↗
录屏需要安装 FFmpeg 吗？+

全屏和区域无声录屏直接使用 Windows 原生媒体能力，保存 H.264 MP4，无需安装 FFmpeg。录音、视频剪辑和 WMV 转换属于可选扩展，需要另行配置 FFmpeg。

支持什么系统和文件格式？+

便携版面向 Windows x64；原生录屏需要系统具备 Windows 媒体组件。图像支持 PNG、JPEG、BMP、GIF、TIFF，也可导出单页 PDF。GIF/TIFF 仅处理首帧或首页。

可以长截图吗？+

支持手动滚动采集与拼接。先选择纯滚动内容区域，再向下滚动，按 F8 采集、F9 完成。每屏需要保留重叠内容；当前不支持自动滚动。

开源吗？如何反馈问题？+

项目使用 MIT 许可证，可查看、修改和构建源码。欢迎在 GitHub Issues 提交问题，附上版本、Windows 缩放比例和复现步骤。多屏混合 DPI、真实音频和长时间录像仍有待进一步验证，详见验证记录。
