A FEW USEFUL DETAILS

Know the details.

Read the usage guide (中文)↗
Do I need FFmpeg to record?+

Silent recording uses native Windows media capabilities and saves H.264 MP4 without FFmpeg. Audio recording, video trimming and WMV conversion are optional features that require a separately configured FFmpeg.

Can I exit without saving a recording?+

Yes. Finishing a recording or closing the recorder gives you a choice to save, discard or return. You can also discard while recording or paused. Canceling the save dialog keeps the recording available to resume or discard.

Which systems and formats are supported?+

The portable build targets Windows x64. Native recording requires Windows media components. Image formats include PNG, JPEG, BMP, GIF and TIFF, plus single-page PDF export. Only the first frame or page of GIF / TIFF is handled.

Can I take scrolling screenshots?+

Manual scrolling capture and stitching are supported. Select the scrolling content area, scroll down, press F8 to capture and F9 to finish. Leave overlap between captures. Automatic scrolling is not currently supported.

How can I report an issue?+

Open a GitHub issue with your app version, Windows display scaling and reproduction steps. Physical mixed-DPI displays, audio and long recordings still need further validation. See the validation record (中文) for tested coverage.
