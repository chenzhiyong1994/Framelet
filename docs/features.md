# 帧简 Framelet 0.2.1 功能说明

帧简 Framelet 面向日常高频场景，具体范围以 [README 的产品范围](../README.md#产品范围) 为准。核心工作流为截图、标注、复制/保存，以及基础录屏和裁剪。

下表说明当前功能与使用边界。Office/FTP、扫描仪、复杂视频特效和完整矢量对象编辑不属于当前产品范围；未验证的场景单独列明。

| 功能 | 当前实现 | 边界 |
| --- | --- | --- |
| 悬浮工具栏、通知区域、快捷键、设置 | 已实现 | 快捷键冲突会提示；可切换数字组合。不同电脑的 DPI、多屏和快捷键占用仍需现场验证。 |
| 活动窗口、窗口/对象、矩形、手绘、全屏、固定区域、重复捕捉 | 已实现常用路径 | 基于桌面可见像素与窗口边界；不承诺获取遮挡、最小化或受保护窗口的隐藏内容。 |
| 延迟、鼠标指针、时间戳、自动保存、定时截图 | 已实现 | 定时截图为全屏并写入设置中的文件夹，受磁盘权限与剩余空间影响。 |
| 滚动窗口长截图 | 支持手动采集 | 手动滚动，`F8` 采集、`F9` 拼接；最多 50 屏及总像素限制。按静态垂直重叠匹配，不消除固定标题或悬浮元素，不自动驱动滚动。 |
| 编辑器、剪贴板、文件、打印机输出 | 已实现常用路径 | 支持本地输出；真实打印机输出需在用户设备验证。 |
| PNG、JPEG、BMP、GIF、TIFF | 已实现静态图像读写 | GIF 只处理首帧，TIFF 只处理首页；不保留动画、多页结构或所有原始元数据。 |
| PDF | 支持单页导出 | 单页栅格导出；不提供 PDF 导入、多页排版或可编辑文本/矢量导出。 |
| 多标签、缩放、裁剪、大小、旋转、镜像、颜色处理 | 已实现常用路径 | 颜色处理包括灰度、负片和亮度调整。 |
| 绘图、箭头、文字、序号、画笔、形状、高亮、马赛克 | 支持像素标注 | 每次提交写入像素，支持会话内撤销/重做；没有独立对象层或再次选择移动已提交标注的能力。 |
| 边缘、标题、图像合并 | 已实现基本路径 | 合并按标签顺序水平或垂直排列；不是自动内容识别排版。 |
| 全屏/区域录像、帧率、鼠标、暂停恢复 | 已实现 | 全屏录像指主显示器；暂停使用分段编码，保存时合并。依赖外部 FFmpeg，支持 MP4/WMV。 |
| 麦克风/音频设备 | 支持 DirectShow 设备 | 提供 DirectShow 枚举与可选音频采集，默认关闭；设备枚举已验证，真实音频录制尚未验证。 |
| 扬声器声音、摄像头 | 未实现专用采集 | 不支持专用扬声器回环或摄像头叠加；若系统另提供 DirectShow 回环设备，可作为音频设备选择，但本轮未验证。 |
| 视频编辑 | 支持首尾裁剪与转码 | 缩略帧预览、起止裁剪、MP4/WMV 转码、音轨保留、进度与取消；不支持视频对象注释、多轨时间线或复杂合成。 |
| 取色、放大镜、标尺、聚光灯、十字线 | 已实现基础工具 | 取色基于启动时的静态截图；标尺以像素计量。具体 UI 验证见验证记录。 |
| WebP、PCX、TGA | 未实现显式支持 | 不将系统偶然可解码的文件视为已支持格式。 |
| Office、FTP、邮件集成、扫描仪 | 未实现 | 当前只提供本地编辑、文件、剪贴板和打印入口。 |

## 验证依据

- 图像处理与标注由 `EditorSelfTests` 检查；主应用自检另覆盖设置往返、异常输入和常用图像格式导出。捕捉/拼接有独立验证工程。
- 录屏模块已通过合成画面的真实 H.264/WMV 编码、暂停计时、恢复与分段合并，两种格式均通过完整解码。
- 视频裁剪已把测试素材导出为约 1.2 秒的 MP4/WMV，检查时长、尺寸、预览帧和完整解码，并验证拒绝非法范围及覆盖输入原文件。
- 音频测试只枚举设备，没有采集用户音频。上述编码测试不代表已验证真实桌面录像或全部交互。

统一运行入口为 `scripts/test.ps1`；增加 `-WithRecording` 执行 FFmpeg 检查。最终界面操作、截图和人工验证范围由 [validation.md](validation.md) 单独记录。
