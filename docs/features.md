# 帧简 Framelet 0.6.0 功能说明

帧简 Framelet 面向日常高频场景，具体范围以 [README 的功能边界](../README.md#轻巧也有明确边界) 为准。核心工作流为截图、标注、复制/保存，以及基础录屏和裁剪。

下表说明当前功能与使用边界。Office/FTP、扫描仪、复杂视频特效和完整矢量对象编辑不属于当前产品范围；未验证的场景单独列明。

| 功能 | 当前实现 | 边界 |
| --- | --- | --- |
| 悬浮工具栏、通知区域、快捷键、设置 | 小标题与单行图标，悬停显示名称和快捷键；支持四边吸附、自动收为图标与悬停/点击展开 | 打开下拉菜单时保持展开，拖离边缘恢复自由悬浮；快捷键冲突会提示，可切换数字组合。真实混合 DPI 多屏仍需现场验证。 |
| 完整窗口、窗口/对象、矩形、手绘、单屏、固定区域、重复捕捉 | 窗口与屏幕截图先高亮目标，再点选确认；多屏可用 Tab / Shift+Tab 切换，Enter 确认，Esc / 右键取消 | 基于桌面可见像素与窗口边界；不承诺获取遮挡、最小化或受保护窗口的隐藏内容。 |
| 延迟、鼠标指针、时间戳、自动保存、定时截图 | 已实现 | 定时截图仍采集包含所有显示器的整个虚拟桌面，并写入设置中的文件夹，受磁盘权限与剩余空间影响。 |
| 滚动窗口长截图 | 框选区域或点选屏幕后自动向下滚动、采集并拼接，到底自动完成 | `F8` 暂停/继续、`F9` 完成、`Esc` 取消。固定顶底栏仅保留一次；无法可靠对齐时暂停并保留已采集部分。高度最多 64000 像素，总计最多 8000 万像素；动态内容、悬浮遮挡及复杂重复纹理可能需要重新框选。 |
| 编辑器、剪贴板、文件、打印机输出 | 七项顶部菜单与图文工具栏分别布局，图像标签和底部状态栏独立 | 支持本地输出；真实打印机输出需在用户设备验证。 |
| PNG、JPEG、BMP、GIF、TIFF | 已实现静态图像读写 | GIF 只处理首帧，TIFF 只处理首页；不保留动画、多页结构或所有原始元数据。 |
| PDF | 支持单页导出 | 单页栅格导出；不提供 PDF 导入、多页排版或可编辑文本/矢量导出。 |
| 多标签、缩放、裁剪、大小、旋转、镜像、颜色处理 | 默认实际大小 100%，可手动适合窗口；编辑器支持拖动图像四边或四角预览裁切，松开应用，Ctrl+Z 撤销 | 拖动中 Esc / 右键取消，内部仍可选择区域。颜色处理包括灰度、负片和亮度调整。大图在实际大小下通过滚动浏览。 |
| 绘图、箭头、文字、序号、画笔、形状、高亮、马赛克 | 左侧双列图标提供工具，悬停显示名称；底部调整颜色、线宽和字号 | 每次提交写入像素，支持会话内撤销/重做；没有独立对象层或再次选择移动已提交标注的能力。 |
| 边缘、标题、图像合并 | 已实现基本路径 | 合并按标签顺序水平或垂直排列；不是自动内容识别排版。 |
| 全屏/区域录像、帧率、鼠标、暂停恢复 | 全屏录像可点选显示器；设置按范围与选项纵向分组，窗口随内容调整；默认无声，使用 Windows 原生能力直接保存 H.264 MP4 | 全屏录像只录所选屏幕；无需 FFmpeg。需要 Windows 媒体组件，暂停期间不写入画面。取消保存可继续录制；目标文件写入失败可重选位置，已结束编码的录像不能追加画面。 |
| 录像选区与开始提示 | 拖动时显示尺寸，松开后可拖动内部移动、拖动四角调整，再确认、重选或取消；开始前有 3 秒倒计时 | Enter / 空格确认；方向键移动，Shift + 方向键调整大小；Esc / 右键取消选区，Esc 取消倒计时。选区至少 2 × 2 像素。 |
| 录制控制条与边框 | 持续边框标示录制范围，红色表示录制中、黄色表示已暂停，标签显示状态与尺寸；控制条常驻计时、暂停、结束和放弃按钮 | 边框不拦截鼠标。Ctrl+F10 暂停/继续，Ctrl+F11 结束。使用 Windows 窗口捕获排除能力避免将控制条、边框和录像设置窗口录入视频，排除设置失败则不开始。 |
| 录像保存与放弃 | 结束或关闭录像机时先选择保存、放弃或返回；只有保存才要求指定位置，放弃并退出直接关闭录像机 | 录制中和暂停时均可直接确认放弃；只删除本次未保存的临时录像。取消保存后保留暂停状态，可继续、放弃或重选保存位置。 |
| 麦克风/音频设备 | “录音设置…”提供 DirectShow 设备枚举与音频采集 | 默认关闭，需另行安装 FFmpeg；有声录制支持 MP4/WMV，使用分段编码与合并。设备枚举已验证，真实音频录制尚未验证。选择“不录制声音”可返回原生录屏。 |
| 扬声器声音、摄像头 | 未实现专用采集 | 不支持专用扬声器回环或摄像头叠加；若系统另提供 DirectShow 回环设备，可作为音频设备选择，但本轮未验证。 |
| 视频编辑 | “视频剪辑…”支持首尾裁剪与转码 | 需另行安装 FFmpeg；支持缩略帧预览、起止裁剪、MP4/WMV 转码、音轨保留、进度与取消。不支持视频对象注释、多轨时间线或复杂合成。 |
| 取色、放大镜、标尺、聚光灯、十字线 | 已实现基础工具 | 取色基于启动时的静态截图；标尺以像素计量。具体 UI 验证见验证记录。 |
| WebP、PCX、TGA | 未实现显式支持 | 不将系统偶然可解码的文件视为已支持格式。 |
| Office、FTP、邮件集成、扫描仪 | 未实现 | 当前只提供本地编辑、文件、剪贴板和打印入口。 |

## 验证依据

- 图像处理与标注由 `EditorSelfTests` 检查；主应用自检另覆盖设置往返、异常输入和常用图像格式导出。捕捉/拼接有独立验证工程。
- 默认自检包含 Windows 原生 H.264 MP4 合成画面编码。原生录制、保存重试与桌面交互的本轮结果见验证记录。
- FFmpeg 扩展已通过合成画面的真实 H.264/WMV 编码、暂停计时、恢复与分段合并，两种格式均通过完整解码。
- 视频裁剪已把测试素材导出为约 1.2 秒的 MP4/WMV，检查时长、尺寸、预览帧和完整解码，并验证拒绝非法范围及覆盖输入原文件。
- 音频测试只枚举设备，没有采集用户音频。上述编码测试不代表已验证真实桌面录像或全部交互。

统一运行入口为 `scripts/test.ps1`，默认执行原生 MP4 编码检查；增加 `-WithRecording` 执行可选 FFmpeg 检查。最终界面操作、截图和人工验证范围由 [validation.md](validation.md) 单独记录。
